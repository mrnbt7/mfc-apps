# Apps in this Repository

## 1. CppApp: is a C++ console application that demonstrates  with Main function.
## 2. BasicApp: is a Win32 Destop application that demonstrates  with WinMain function.
## 3. Win32App: is a Win32 Desktop application that demonstrates with Window creation.
## 4. WinDialog: is a Win32 Desktop application that demonstrates with Dialog creation.

## steps to run the applications:
1. open the solution file in Visual Studio.
2. select the desired application project in the Solution Explorer.
3. set the selected project as the startup project (Right-click on the project > Set as Startup Project).
4. Build the solution (Ctrl + Shift + B) to compile the selected application.
5. Run the application (F5) to execute the selected application.
